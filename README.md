# Kids Area — تطبيق منطقة الأطفال (مستقل — مكتمل)

## التشغيل

### Backend
```bash
cd backend/KidsArea.Api
dotnet restore
dotnet run
```
API: http://localhost:5000 — Swagger: /swagger

### Frontend
```bash
cd frontend
npm install
npm run dev
```
http://localhost:3000

## الدخول
| مستخدم | كلمة المرور | دور |
|--------|-------------|-----|
| owner | Owner@123 | مالك |
| cashier | Cashier@123 | كاشير |

## الهوية البصرية (مكتمل)
من **الإعدادات → الهوية والصور** (المالك):
- رفع **الشعار** من الجهاز
- رفع **خلفية تسجيل الدخول**
- رفع **خلفية الرئيسية**
- إزالة أي صورة
- تظهر في: شاشة الدخول، الشريط العلوي، إيصال الدخول

الصور تُحفظ في `wwwroot/uploads` وتُعرض بدون إنترنت بعد الرفع.

## أوفلاين
بعد `dotnet restore` و `npm install` مرة واحدة، التشغيل اليومي لا يحتاج إنترنت (SQLite محلي).

## القواعد
- أسعار من الإعدادات فقط
- باقات فردية + أخوة + مرافقين + حقل مرن
- عضويات فردية / حفلات بسيطة
- QR + بحث جزئي + ماسح
- إقفال يومي + تقرير عربي للطباعة
- لا مصروفات داخل التطبيق
